# 実装仕様

更新日: 2026-10-01

この文書は、会話で合意した Personal Viewer の実装方針をまとめたものです。既存の specification.md を基礎とし、会話で確定した内容が異なる場合は、この文書の新しい決定を優先します。未決事項は末尾にまとめます。

## 1. アプリケーションの前提

- アプリ名は Personal Viewer。
- C# と WPF で実装する Windows デスクトップアプリ。
- 通常操作は単一のメインウィンドウで行う。タグ編集のための別ウィンドウは作らない。
- プロジェクト作成など、必要な入力には小さなダイアログを利用してよい。
- プロジェクト、設定、ファイル情報は Documents\PersonalViewer 以下に保存する。
- ウィンドウの位置と大きさ、最後に開いたプロジェクトを保存し、次回起動時に復元する。

## 2. メインウィンドウの配置

スクリーンショットを配置の参考とし、次の領域を持つ。

1. 上部に File と Help のメニューを置く。
   - File: 新規プロジェクト、プロジェクトにフォルダーを追加、終了。
   - Help: このアプリケーションについて。
2. 上部の操作領域に検索欄、プロジェクト選択、詳細表示／サムネイル表示の切り替えを置く。
3. 検索欄の直下に、現在選択しているファイルのタグを表示する領域を置く。
4. メイン領域を左右に分け、左に TreeView、右に検索結果を表示する。
5. ウィンドウ最下部に一行分のステータス領域を確保し、メッセージを左寄せで表示する。スキャンの進行・完了など、通知レベルのメッセージに使う。深刻なエラーは MessageBox などのダイアログで表示することを検討する。

タグ領域や結果一覧が長くなる場合は、該当領域内でスクロールできるようにする。

## 3. プロジェクト作成とメディア種別

- 新規プロジェクトの作成時に、プロジェクト名、最初の登録フォルダー、メディア種別を指定する。
- プロジェクト作成には最低一つのフォルダー登録が必要。
- メディア種別はアプリ設定 YAML に定義されたグループから一つ選ぶ。動画用・画像用に固定せず、設定ファイル内に定義された名前と拡張子の組を選択肢として表示する。
- 動画と画像の両方を扱う場合は、設定ファイルに「動画と画像」などのグループを定義して選ぶ。
- 拡張子グループの追加・変更は、ユーザーが Documents\PersonalViewer 内の YAML 設定ファイルを編集して行う。
- 拡張子は小文字に正規化して扱い、実ファイルとの比較では大文字・小文字を区別しない。
- プロジェクトには選択したメディア種別と登録フォルダーを保存する。

## 4. 検索とフォルダー表示

検索は、フォルダー表示とキーワード検索を同時に適用しない。次の状態を切り替える。

### 4.1 検索欄が空

検索結果を表示しない。

### 4.2 TreeView でフォルダーを選択

- 既存の検索文字列をクリアする。
- 検索欄に「:folder:」と選択フォルダーのパスをつないだ値を表示する。
- 選択フォルダー直下にあるファイルだけを結果に表示する。サブフォルダー内のファイルは含めない。
- TreeView のフォルダー階層は登録フォルダーを起点として表示する。

### 4.3 キーワード検索

- 通常の文字列を入力すると、プロジェクト全体を対象に検索する。TreeView で選択中のフォルダーによる絞り込みとは組み合わせない。
- ファイル名は部分一致で検索する。ディレクトリー部分はファイル名検索の対象にしない。
- タグ名も部分一致で検索する。
- 空欄に戻した場合は結果を表示しない。

## 5. フォルダー登録とスキャン

- 新規プロジェクト作成時、最初に登録したフォルダーを直ちに再スキャン相当の処理にかける。
- 「プロジェクトにフォルダーを追加」を実行したときは、新しく追加したフォルダーを直ちに再スキャン相当の処理にかける。
- TreeView のフォルダー項目を右クリックし、「再スキャン」を実行できる。
- いずれのスキャンも対象フォルダー以下のサブフォルダーを含めて再帰的に走査する。
- 結果一覧のフォルダー表示範囲は直下のファイルのみであり、スキャン範囲とは別に扱う。
- 選択中プロジェクトのメディア種別に定義された拡張子のファイルだけを登録する。
- YAML の拡張子設定を変更しても自動スキャンは行わない。変更を反映するには対象フォルダーを再スキャンする。
- スキャンの進行・完了などの通知レベルのメッセージは、ウィンドウ下部の一行ステータス領域に表示する。

## 6. タグ表示と操作

- タグ表示領域は検索欄の直下に置き、検索結果で選択中のファイルに対応するタグを表示する。
- ファイルを一つ選択したときは、そのファイルのタグだけを表示する。
- タグの追加は「+」操作で入力欄を表示し、追加したタグを選択中のファイルすべてに付与する。
- 各タグラベルの右側に「×」を置き、クリックで削除する。
- 複数ファイル選択時は、選択ファイルに付いているタグの集合を表示する。タグごとに「付与されているファイル数／選択ファイル数」を表示する。例: 選択5件のうち2件に付いているタグは「2/5」。
- 複数選択時にタグを追加すると、選択中の全ファイルに付与する。
- 複数選択時にタグを削除すると、そのタグを持つ選択ファイルからだけ削除する。
- タグ表示が領域を超える場合、タグ領域内をスクロール可能にする。

## 7. 検索結果の表示と操作

- 詳細表示とサムネイル表示を上部の切り替え操作で選べる。
- 結果一覧は必要に応じてスクロール可能とする。
- 複数項目は Ctrl／Shift を使った標準的な複数選択に対応する。
- 項目をダブルクリックすると、OS に関連付けられたアプリで開く。動画は関連付けられたプレーヤーで再生する。
- Windows から取得できるサムネイルを利用し、サムネイルキャッシュは %LOCALAPPDATA%\PersonalViewer\Cache\Thumbnails に保存する。

## 8. 保存データ

- プロジェクトは Documents\PersonalViewer 以下にプロジェクトごとのフォルダーを作って保存する。
- アプリ共通設定には、メディア種別と拡張子の対応を YAML 形式で保存する。
- プロジェクトごとに登録フォルダー、ファイル一覧、ファイルとタグの対応を保持する。
- 設定やキャッシュの形式は TSV または YAML を基本とする。ファイル一覧など、行ごとのフルパスが適するデータは TXT を利用してよい。
- フォルダー表示順は既定で名前順とし、既定と異なる場合だけカスタム順を保存する。

## 9. 未決事項

- アプリ共通 YAML 設定ファイルの名前、正確なスキーマ、初期状態で用意するメディア種別と拡張子一覧。
- 検索における大文字・小文字の扱い。
- 登録フォルダーが複数ある場合に、:folder: の表示文字列でどの登録ルートを識別するか。
- 詳細表示の列、サムネイルの大きさ、ファイル結果の並び順。
- 再スキャンで削除済み・拡張子対象外になったファイルの既存インデックスをどう更新するか。
- MessageBox などのダイアログを表示する深刻なエラーの基準。
