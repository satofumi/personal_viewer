# 概要

- C# + WPF アプリにする。
- アプリ名: Personal Viewer
- 基本的に１つのウィンドウで動作する。
  - 設定などは別ウィンドウになる。

# UI 構成

## メニュー

- File:
  - 新規プロジェクトの作成
  - プロジェクトにフォルダを追加
    - 登録されている拡張子のファイルしか扱わない。
  - 終了

- Help:
  - このアプリケーションについて

## プロジェクト切り替えのコンボボックス

- 登録されてるプロエクトを選ぶ。

## 結果表示の切り替えのボタン

- 詳細表示ボタンｎ
- サムネイルボタン

## 検索欄

- ここに入力した文字列について
  - ファイル名と文字列が一致すればそのファイルを結果として表示する。
    - ディレクトリ部分の文字列とはマッチングしない。
  - タグと一致すれば、そのタグを持つファイルを結果として表示する。

- フォルダの TreeView のフォルダがクリックされたときには、そのフォルダパスを検索欄に表示する。
  - :folder:Directory\to\clicked のように先頭に :folder: を付与して以降はそのディレクトリのパスを続ける。
    - プロジェクトに登録されたディレクトリを表示の際のトップとして表示する。


## TreeView

- プロジェクトに登録されたディレクトリが並んでおり、TreeView の操作で階層を開いたり閉じたりできる。
- ディレクトリの項目がクリックされたとき、そのディレクトリにあるファイルを結果として表示する。
- 項目で右クリックして「再スキャン」を実行してファイル情報を更新できる。


## 結果表示欄

- (サムネイル画像 + ファイル名) か詳細表示が行える。
  - この切り替えはアプリ上部のアイコンで切り替える。
- 必要に応じてスクロールバーが右側に表示される。
- ここに表示される項目をダブルクリックすると、対応するアプリで閲覧および動画再生を行う。

- Explorer と同様に Ctrl や SHIFT 押下しながらの左クリックで項目を選択することができ、選択した項目にまとめて「タグの追加」や「タグの削除」を行えるようにする。


# プロジェクトごとの設定項目

- 登録するファイルの拡張子
  - 小文字にして判別する。（大文字小文字は区別しない）
- プロジェクトに登録したディレクトリ


# 検索用のファイル構成

- プロジェクトごとにフォルダを作成する。
  - MyDocument の PersonalViewer ディレクトリにこれらのプロジェクトを保持する。


# 基本動作

- 前回のアプリ位置と大きさを保持して起動する。
- コンボボックスで開いたプロジェクトは次回起動時に保持される。
- アイコンのサムネイル画像のキャッシュは %localappdata%\PersonalViewer\Cache\Thumbnails に保存する。
  - 読み取れれば Windows のサムネイル画像を利用する。
- 設定ファイルやファイルのキャッシュは .tsv か .yaml にする。
- プロジェクトごとに必要なファイルを保持する。
  - ファイルのフルパスが行ごとに記述された .txt ファイル
  - ファイルとタグとの関連を保持する .yaml ファイル
  - プロジェクトに登録したディレクトリのフルパスが記述された .txt ファイル
  - ディレクトリとソート順を保持した .yaml ファイル
    - デフォルトは名前の辞書順に表示する。それ以外の設定のときだけ保持する。
- TreeView のディレクトリの項目をクリックすると :folder: とそのパスとをつなげた文字列を検索欄に表示する。
  - :folder: の文字列が先頭になければ検索ワードとして扱う。
